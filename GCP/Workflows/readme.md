# Google Cloud Workflows Basics Syllabus

| Module                        | Topic Focus                             | Description                                                                                                                                       | Keywords to Learn                                                                                        |
| ----------------------------- | --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| **1. The Fundamentals** | **Introduction to Orchestration** | Understand what Workflows does and how it differs from simply triggering functions directly (Choreography).                                       | `Serverless`, `Orchestration vs. Choreography`, `Microservices`, `Stateful vs. Stateless`        |
| **2. Core Syntax**      | **Writing your First Workflow**   | Learn the markup languages used to define workflows, how a workflow is structured, and how execution moves from top to bottom.                    | `YAML`, `JSON`, `main`, `steps`, `step names`                                                  |
| **3. Managing Data**    | **Variables and Expressions**     | Learn how to store data, retrieve information, and manipulate values as your workflow progresses.                                                 | `assign`, `Variables`, `Expressions (${})`, `Data Types (String, Int, Boolean, Map, List, Null)` |
| **4. Control Flow**     | **Making Decisions & Looping**    | Discover how to make your workflow execute conditionally based on data, skip steps, or repeat tasks.                                              | `switch`, `condition`, `next`, `for` (iteration), `return`, `Subworkflows`                   |
| **5. Integration**      | **Making API Calls**              | The core feature of Workflows—calling out to external services, Google Cloud APIs, and serverless functions (like Cloud Run or Cloud Functions). | `call`, `http.get`, `http.post`, `args`, `result`, `headers`, `Authentication`             |
| **6. Resilience**       | **Handling Errors**               | Learn what happens when a service you are trying to reach is down, and how to catch those errors or retry the step.                               | `try`, `except`, `retry`, `Raise errors`, `Custom Retry Policies`                              |
| **7. Authentication** | **Securing Service Calls** | Authenticate requests to Google Cloud and external services using service accounts, OAuth 2.0, OIDC, API keys, and least-privilege IAM permissions. | `Service Accounts`, `IAM`, `OAuth 2.0`, `OIDC`, `API Keys`, `Scopes`, `Least Privilege` |
| **8. Connectors** | **Calling Google Cloud Services** | Use built-in connectors and Google APIs to integrate with Cloud Run, Cloud Functions, Pub/Sub, BigQuery, and other Google Cloud services. | `Connectors`, `googleapis.*`, `Cloud Run`, `Pub/Sub`, `BigQuery`, `Long-Running Operations` |
| **9. Advanced Design** | **Reusable and Concurrent Workflows** | Build maintainable workflows with subworkflows, parameters, return values, parallel execution, concurrency limits, shared state, and environment variables. | `Subworkflows`, `Parameters`, `Return Values`, `parallel`, `Concurrency`, `Environment Variables` |
| **10. Deployment** | **Managing the Workflow Lifecycle** | Create, deploy, execute, update, inspect, and delete workflows using the console, CLI, APIs, and infrastructure as code. | `gcloud workflows`, `Deploy`, `Execute`, `Revisions`, `Terraform`, `CI/CD`, `Regions` |
| **11. Observability** | **Monitoring and Debugging** | Inspect execution history and step results, read logs, measure failures and latency, and diagnose issues in development and production. | `Execution History`, `Cloud Logging`, `Cloud Monitoring`, `Audit Logs`, `Tracing`, `Debugging` |
| **12. Limits and Cost** | **Performance and Optimization** | Design within quotas and execution limits, control timeouts and parallelism, manage payload sizes, and optimize external API usage and cost. | `Quotas`, `Limits`, `Timeouts`, `Payload Size`, `Concurrency`, `Billing`, `Cost Optimization` |
| **13. Testing** | **Validating Workflow Behavior** | Test success, failure, timeout, retry, branching, parallel, authentication, and idempotency scenarios before and after deployment. | `Unit Testing`, `Integration Testing`, `Test Data`, `Mocks`, `Idempotency`, `Cloud Build` |
| **14. Production Practices** | **Reliable and Secure Architecture** | Apply input validation, secret management, versioning, dead-letter handling, disaster recovery, security, and least-privilege production practices. | `Secret Manager`, `Input Validation`, `Idempotency`, `Dead-Letter`, `Versioning`, `SLOs`, `Disaster Recovery` |
