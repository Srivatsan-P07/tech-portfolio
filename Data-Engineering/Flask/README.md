## **Python Flask Course Content (Tabular Format)**

| **Module**                              | **Topics Covered**                                                                     | **Outcomes**                                    |
| --------------------------------------- | -------------------------------------------------------------------------------------- | ----------------------------------------------- |
| **1. Basics of Python for Web**         | Python syntax, virtual environments, packages (pip), file structure                    | Able to set up Python projects and environments |
| **2. Introduction to Flask**            | What is Flask? Installing Flask, "Hello World", app routes, debug mode                 | Build your first Flask app                      |
| **3. Flask Routing & Request Handling** | GET & POST requests, route parameters, form submission                                 | Handle dynamic URLs & forms                     |
| **4. Templates (Jinja2)**               | Template rendering, variables, loops, conditionals, template inheritance, static files | Build dynamic HTML pages                        |
| **5. Forms & User Input**               | Flask-WTF (optional), CSRF token, validation, request.form, file upload                | Secure and validate user input                  |
| **6. Database Integration**             | SQLite basics, SQLAlchemy ORM, migrations with Flask-Migrate                           | Store, query, update, delete data               |
| **7. User Authentication**              | Login/Logout, hashing passwords (Werkzeug), sessions, cookies                          | Create secure login system                      |
| **8. APIs in Flask**                    | REST principles, returning JSON, Flask jsonify, building API endpoints                 | Build backend API services                      |
| **9. Error Handling & Logging**         | Custom error pages (404, 500), Flask error handlers, logging                           | Improve app stability                           |
| **10. Structuring Large Flask Apps**    | Blueprints, application factory pattern, config files                                  | Build scalable project architecture             |
| **11. Frontend Integration**            | Using Bootstrap/Tailwind, passing data to templates, AJAX fetch calls                  | Create modern UI + backend integration          |
| **12. Background Jobs**                 | celery (optional), threading, scheduled jobs                                           | Handle asynchronous processes                   |
| **13. Testing Flask Apps**              | pytest, mocking, client testing, test database                                         | Write automated tests                           |
| **14. Deployment**                      | Gunicorn, uWSGI, Nginx setup, Docker for Flask, environment variables                  | Deploy Flask apps to production                 |
| **15. Cloud Deployment**                | GCP Cloud Run, AWS EC2, Heroku (if needed), CI/CD basics                               | Deploy to cloud platforms                       |
| **16. Security Best Practices**         | XSS, CSRF, SQL Injection prevention, secure cookies, rate limiting                     | Build secure applications                       |
| **17. Real Project**                    | End-to-end project: auth, dashboard, CRUD, API, deployment                             | Apply everything learned                        |
